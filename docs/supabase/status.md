## supabase-status

Shows status of the Gentabase local development stack.

Requires the local development stack to be started by running `gentabase start` or `gentabase db start`.

You can export the connection parameters for [initializing supabase-js](https://gentabase.dev/docs/reference/javascript/initializing) locally by specifying the `-o env` flag. Supported parameters include `JWT_SECRET`, `ANON_KEY`, and `SERVICE_ROLE_KEY`.
